九转一键还原（SysRecover）使用说明
==================================

一、这是什么
  把当前 Windows 系统备份成一个镜像文件（.esd/.wim），需要时一键还原回去。
  · 还原「系统盘」：会暂存任务并自动重启，进入内置救援层执行（全自动）。
  · 还原「非系统盘」（或在 PE 里）：自动「就地还原」，不重启。

二、怎么用（图形界面）
  1. 解压整个文件夹（保持目录结构），双击 SysRecoverUI.exe（会弹一次 UAC，允许即可）。
  2. 备份：切到「系统→文件」→ 选保存位置（也可手输或把路径拖进窗口）→ 点「开始备份系统」。
  3. 还原：切到「文件→系统」→ 选镜像（也可直接把 .esd/.wim 拖进窗口）→ 选目标分区
     → 点「开始恢复系统」→ 选「退出并重启」→ 之后全自动，最后自动回到新系统。
  · 无人值守：勾上「静默模式」，全程无对话框。

三、重要提示（务必看）
  · 镜像文件必须放在「本地分区」（如 D:\ 或 U 盘）。还原系统盘要重启进救援层，
    而救援层（Linux）访问不到网络（UNC / 映射网络驱动器）→ 放网络位置会失败。
  · 还原会「清空目标分区」，请先备份该分区里的重要数据。
  · 程序需要管理员权限（读写分区与引导），这是正常的。
  · 支持：BIOS/MBR、UEFI/GPT、Secure Boot 开/关；Windows 7 / 10 / 11 / WinPE。
  · 不支持 Windows 2003 / XP / Vista 及更早系统。

四、出问题怎么办
  · 程序目录 logs\ 里有运行日志（崩溃日志在 logs\crash\）；点界面右下角「讨论」反馈，
    或把 logs\ 打包发回。
  · 若还原没成功、开机又回到原系统，先看 logs\ 里最新的日志文件。

五、目录说明
  SysRecover.exe / SysRecoverUI.exe  入口（自动按系统位数选 x86/x64）
  x64\                               64 位程序与依赖
  bootfiles\                         内置救援层（还原时使用）
  skin\  resources\                  界面资源
  libwim-15.dll  api-ms-win-*.dll    运行库（请勿删除）
  THIRD_PARTY_LICENSES.txt           第三方组件许可
