**跑起来（三条命令）**：

```bat
:: 1) 编译（先保证工具链在 D:\Prog\ProgIDE\mingw64）

:: 2) 自检（会打印管理员 / 固件类型 / Secure Boot / wimlib 版本）

:: 3) 打包发布物（dist\ 里含 exe + bootfiles + 皮肤 + 许可 + version.json）
mingw32-make -f Makefile package
```

## 6. 五条红线（摘要，动手前**必看** `AGENTS.md` §0）

1. **重启类还原/备份必须走 Linux**；WinPE/WinRE 只用于"就地还原"（不重启）。
2. **读磁盘/分区禁用 WMI**（PE 不可用），只用 Win32 API。
3. **BCD 严格按 `AGENTS.md` §7 的成熟命令**（`\grldr.mbr` + `/application bootsector`），严禁自己发明。
4. **只动态链接 libwim**；禁抄 `wimlib-imagex`(GPLv3) / grub4dos 源码 / Dism++ 主程序。
5. **改跨层契约字段必须双端同步发版**（Windows + Linux 救援层）。

## 7. 三个最容易踩的环境坑（细节见 `docs/10` §6）

- **`.ps1` 必须纯 ASCII**（PowerShell 5.1 按 ANSI 解析无 BOM 脚本，中文注释会把解析器打挂）。
- **不要用 `Set-Content -Encoding UTF8` 改 shell 脚本**（会加 BOM → `#!/bin/sh` 失效 → 救援层起不来）。
- **`*.sh` 必须是 LF**（仓库有 `.gitattributes` 强制；救援层脚本 CRLF 会跑不起来）。
