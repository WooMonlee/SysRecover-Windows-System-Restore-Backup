# 备份时打开/锁定文件的处理调研

> 2026-10-23。目标：不再为“某个软件的文件打不开”逐个加排除，而是按行业通用机制处理。

## 1. 同行怎么做

### AOMEI Backupper
- 默认推荐 **VSS（Volume Shadow Copy Service）**；VSS 不可用时才使用自有备份服务。
- 文件被其它程序**独占**、或权限不足时，程序**提示用户跳过**，而不是让整个任务失败。
- VSS 默认排除 Outlook OST（可通过注册表 `FilesNotToSnapshot` 调整）。

来源：AOMEI Backupper User Manual（2.2 System Backup / VSS 说明）。

### Macrium Reflect
- 文件和文件夹备份明确说明：**通过 VSS 备份打开/锁定的文件**。
- 备份可能“成功但带 warning”；提供 warning 邮件、日志/VSS 日志，用户可追溯。

来源：Macrium Reflect Help "Backup up Files and Folders"、File and Folder Backup Options。

### Robocopy（Windows 自带）
- `/B` = backup mode，启用 `SeBackupPrivilege`，解决**权限**问题；
- 但 `/B` **不解决被其它进程打开/锁定**的文件；需要 VSS 快照；
- `/R:n /W:n` 控制重试；`/V` 显示 skipped；日志记录错误，任务继续。

来源：Microsoft Learn Robocopy 文档、社区实践。

### wimlib（本项目使用的库）
- `WIMLIB_ADD_FLAG_SNAPSHOT`：Windows 上通过 VSS 捕获运行中的系统卷，**解决绝大多数打开/锁定文件**。
- `WIMLIB_PROGRESS_MSG_HANDLE_ERROR`：扫描阶段遇到 OS 级错误时，应用可设置
  `handle_error.will_ignore = true` 后继续；这是 wimlib 官方提供的“有限恢复”接口。
- `wimlib_set_error_file_by_name`：把具体失败路径/errno 写到日志。

来源：wimlib API 文档（Progress messages / `WIMLIB_PROGRESS_MSG_HANDLE_ERROR`、`WIMLIB_ADD_FLAG_SNAPSHOT`）。

## 2. 结论

- **不要用“文件级复制”替代 VSS**：VSS 是解决打开/锁定文件的第一层，本项目已启用。
- **VSS 仍可能遇到不可读文件**（云占位、损坏日志、第三方保护软件缓存等）；
  行业做法是**跳过并记录/提示**，而不是整体失败。
- **不要按软件名逐个加排除**：应按**错误类型**统一处理，并把跳过清单交给用户确认。

## 3. 本项目实现（0.9.13）

1. `WimEngine::Capture/Append` 保持 VSS（`WIMLIB_ADD_FLAG_SNAPSHOT`）。
2. `ProgressThunk` 处理 `WIMLIB_PROGRESS_MSG_HANDLE_ERROR`：
   - `WIMLIB_ERR_OPEN/OPENDIR/READ/READLINK/STAT` → `will_ignore=true`；
   - 日志：`backup: skipped unreadable file: <path> (wimlib error=N)`。
3. **只对捕获/追加生效**；`Apply`/`Verify` 不忽略，还原/校验仍 fail-closed。
4. `RunBackup` 汇总跳过路径：
   - GUI 备份完成弹「备份不完整」清单（最多 20 条 + 完整日志路径，静默模式也弹）；
   - CLI 打印清单；
   - 日志写 `backup: incomplete, skipped N`；history 记 `ok-skipped`。
5. 0.9.11 的 OneDrive/AlibabaProtect 排除保留为快速路径，但不再是“每个软件都要发版”的机制。

## 4. 已知边界

- `HANDLE_ERROR` 主要覆盖**扫描阶段**错误；文件数据读取阶段若出现 wimlib 不通过该接口上报的错误，仍可能失败，需要看 `wimlib-errors.log`。
- 跳过文件意味着备份**不完整**；UI/CLI 会明确告知，但不会自动重试或修复源文件。
- 若需要“块级”保真（坏道、极端锁定），需要另做扇区级镜像方案，不在当前 WIM 路径范围内。
