# SysRecover · 构建、发布与许可合规

## 1. 工具链（钉版）

| 项 | 要求 |
|---|---|
| 编译器 | **MinGW-w64 GCC 14.2.0**（`D:\Prog\ProgIDE\mingw64`，x86_64-w64-mingw32，posix-seh） |
| 配置 | `_WIN32_WINNT=0x0601`（Win7 兼容）、`-O2`、**Release x64** |
| 链接 | `-static`（PE 零依赖；仅 `libwim-15.dll` 动态、随包） |
| 子系统 | `-mconsole`（`SysRecover.exe`）/ `-mwindows`（`SysRecoverUI.exe`） |
| 提权 | GUID/CLI 两个 exe 都编入 `requireAdministrator` 清单（windres，PIT-018） |
| Python | 构建脚本用完整路径 `D:\Prog\ProgIDE\Python\Python313\python.exe`（PATH 上的 python 是商店占位符） |

## 2. 构建命令

```bash
mingw32-make -f Makefile all        # CLI + GUI
mingw32-make -f Makefile cli|gui    # 单建
mingw32-make -f Makefile package    # 部署 bootfiles/皮肤/许可声明到 dist/
mingw32-make -f Makefile clean
```

救援层（与主构建解耦，产物进 `bootfiles/`）：

```bash
python tools/build-ubuntu-rescue.py     # Secure Boot 用：Ubuntu 签名内核 + 模块 + Alpine 用户态
python tools/vmtest/build-alpine-initramfs.py   # 纯 Alpine 版（SB 关闭时可用）
```

**关键点**：救援层产物文件名固定（`vmlinuz-zjrestore` / `initramfs-zjrestore.cpio.gz`），
**换内核/模块来源不影响部署逻辑**。

## 3. 发布包（`dist/`，约 54 MB）

```
SysRecover.exe / SysRecoverUI.exe / libwim-15.dll
bootfiles/{grldr, grldr.mbr, vmlinuz-zjrestore, initramfs-zjrestore.cpio.gz, zjrestore-lite.sh}
bootfiles/sb/{shimx64.efi, grub-ubuntu.efi, grub.cfg}
skin/ resources/ version.json THIRD_PARTY_LICENSES.txt
```

`version.json` 与 `version` 命令、Windows VERSIONINFO、git tag **三处同源**（SemVer）。

## 4. 门禁

- `objdump -p` 检查导入表：只允许系统 DLL + `libwim-15.dll` + UCRT api-set。
- 体积目标 < 10 MB（exe）；**自有代码零警告**（第三方 Duilib 的历史警告除外，PIT-012）。
- `diag` 自检通过（打印 `firmware=` / `secureboot=` / 启动项状态）。

## 5. 许可合规（结论）

**本产品自身代码未被 copyleft 传染**：未静态链接任何 GPL 组件、未修改任何第三方源码。

| 组件 | 许可 | 用法 |
|---|---|---|
| wimlib（`libwim-15.dll`） | LGPLv3 | **动态链接**，DLL 随包，用户可替换 |
| Duilib（古典） | MIT/BSD | 静态链接进 GUI |
| Alpine 用户态（busybox/musl/ntfs-3g/util-linux/wimlib） | GPLv2 / MIT / LGPL | 仅分发二进制（未修改），**聚合** |
| Ubuntu 内核 + 模块 | GPLv2 | 仅分发二进制（未修改，Canonical 签名），聚合 |
| GRUB（Canonical 签名） | GPLv3 | 仅分发已签名二进制（未修改），聚合 |
| shim（`shimx64.efi`） | BSD-2-Clause | 仅分发已签名二进制（未修改） |
| GRUB4DOS（`grldr*`） | GPLv2 | 仅分发官方二进制（未修改） |
| **禁止引入** | — | `wimlib-imagex` 源码、GRUB4DOS 源码、Dism++ 主程序 |

- 组件清单 + 各许可全文：**`THIRD_PARTY_LICENSES.txt`**（`make package` 拷进 `dist/`）。
- 构建/测试期工具（MinGW-w64、osslsigncode、QEMU/OVMF、mtools、zstd）**不随产品分发**。
- **是否开源为待决事项**（合规上无阻碍，属商业决定；见 `PLAN.md` §10）。

## 6. 备选线（默认不编译、不随包）

MOK/UKI 路线（`固件 → shim → 我们签名的 UKI`，需一次性 MOK 注册）保留在仓库但**不编译**：

- 开关：`src/boot/uefi.cpp` 的 `#define ZJ_ENABLE_MOK_PATH 0`（改成 1 重新编译即可启用）。
- 资产：`bootfiles/sb/{shimx64.efi, mmx64.efi, fbx64.efi, zj-mok.cer}`、`tools/build-uki.py`、`keys/zj-mok.*`（私钥 gitignore）。
- 启用步骤：改宏 → `Makefile` 的 `package` 里恢复 UKI 构建与资产拷贝（PIT-062 有完整记录）。
