# SysRecover · 磁盘枚举与安全红线

> 文档版本：v1.0（2026-09-20）｜关联：《01-需求与定位》《03-引导设计》
> 一句话：**读盘只用 Win32 API（禁 WMI），危险操作一律 fail-closed（能拒就拒）。**

---

## 1. 允许的 API 白名单（PE 可用）

| 用途 | API |
|---|---|
| 打开物理盘/卷 | `CreateFile(\\.\PhysicalDriveN)`、`CreateFile(\\.\X:)` |
| 分区表 | `DeviceIoControl(IOCTL_DISK_GET_DRIVE_LAYOUT_EX)` |
| 卷信息 | `GetVolumeNameForVolumeMountPoint`、`GetDriveType`、`GetLogicalDrives` |
| 盘符 ↔ 分区 | `IOCTL_DISK_GET_PARTITION_INFO_EX`、`IOCTL_DISK_GET_DRIVE_GEOMETRY_EX` |
| 固件类型 / ESP | `GetFirmwareEnvironmentVariable`（读 `SecureBoot`）、固件启动项读写 |
| 设备信息（可选） | `SetupDi*` |

**禁用**：`WMI`（`Win32_DiskDrive` 等一律不用）—— WinPE 里不可用。

## 2. 返回的数据结构（POD）

```
Disk       { index, serial, size, style(MBR|GPT) }
Partition  { guid, offset, size, letter, fs, label, isEsp/isSystem }
```

## 3. 铁律

- 全工程 `std::wstring` + `CreateProcessW`；路径用 `\\?\` 前缀处理长路径。
- wim 源路径强制 `X:/` 尾斜杠（wimlib 的 Linux 路径风格）。
- **GUID 比较一律用 ASCII**（不受代码页影响，PIT-005 教训）。
- 找系统工具必须 `GetSystemDirectoryW` 拼全路径（`bcdedit.exe` 裸名会 `fail 2`，PIT-010）。

## 4. 还原前四检查（`src/app/safety.cpp`，fail-closed）

1. **目标是 ESP/系统保留分区** → 拒绝。
2. **BitLocker 加密** → 拒绝（需用户先解密/暂停）。
3. **目标是恢复分区/隐藏分区** → 拒绝。
4. **镜像文件在目标分区内** → 拒绝（否则会被一起格式化）；命中时提供"移到数据盘"的处理路径。

另：**GPT 目标仅 UEFI 固件放行**（BIOS+GPT 拒绝，PIT-034）。

## 5. 四元素校验（比对任务与现场）

`GUID` + `磁盘序列号` + `分区偏移(字节)` + `分区大小(字节)` 全部一致才动手；
任一不符 → 拒绝（防止"人换盘/改分区后误还原"）。

## 6. 退出码（CLI 契约）

| 码 | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 通用失败 |
| 2 | 参数错误 |
| 3 | 需要管理员 |
| 4 | 危险目标被拒（安全门禁） |
| 5 | 镜像校验失败（含"写入未完成"的半截镜像，PIT-057） |
| 6 | 用户取消 |

## 7. 其它安全约定

- 改 BCD 前先 `bcdedit /export <软件目录>\logs\bcd-backup`。
- 危险操作（格式化目标分区）必须二次确认，`--yes` 才可跳过。
- 单实例互斥（GUI：`Global\SysRecoverUI_SingleInstance`；任务执行中拒绝被关闭）。
- 备份热备前 `RegFlushKey` 刷注册表 hive，并**随包捕获 `.LOG1/.LOG2`**（否则还原后黑屏，PIT-056）。
