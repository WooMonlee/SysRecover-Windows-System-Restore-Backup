## 1. 产品定位

**一键还原（单机版）/ SysRecover** —— 面向**电脑维修人员 / 系统维护人员 / IT 管理员**的
系统备份与还原工具。原生 C++、CLI 优先（GUI 同源）、零运行时依赖。

**典型场景**：客户机系统损坏/中病毒 → 用之前做的镜像一键还原回干净状态；
或在 PE 里把镜像装到任意分区。

## 2. 目标与非目标

| 项 | 定论 |
|---|---|
| 还原方式 | **镜像应用**（WIM/ESD → `libwim` apply），对**任意已有系统**可用 |
| 系统形态 | **不改动**客户机的系统形态（物理分区原样，不做 VHD 改造） |
| 执行环境 | 正常 Windows（重启进内置 Linux 救援层）**或** PE（就地还原，不重启） |
| 引导 | BIOS/MBR 与 UEFI/GPT 双支持；**Secure Boot 开启时零注册零交互** |
| 体积 | 目标 < 10 MB（当前 `SysRecoverUI.exe` ≈ 2.1MB） |
| 依赖 | **零运行时依赖**（静态链接；仅 `libwim-15.dll` 动态、随包） |
| 非目标 | 多点/秒级快照还原、教师机网络集中管理（属 `OnekeyRestore` 产品线） |
| 非目标 | 系统级隐藏、防 U 盘/PE 攻击（无内核驱动的软件做不到） |

## 3. 环境矩阵

| 环境 | 支持 | 实测 |
|---|---|---|
| BIOS / MBR | ✅ | ✅ |
| UEFI / GPT（Secure Boot 关闭） | ✅ | ✅ |
| UEFI / GPT + **Secure Boot 开启** | ✅（零注册） | ✅ |
| WinPE / 还原到非系统盘 | ✅（就地还原，不重启） | 🚧 待实测 |
| Windows 7 / 10 / 11 | ✅ | 10/11 ✅；**7 装 VC++ 运行库后可用 ✅**，且**已实测 Win7 宿主还原 Win10 镜像并正常启动** |
| **架构** | **仅 x64** | 32 位 Windows / 32 位 PE 需另出 x86 版（x64 exe 在 32 位系统上由系统直接拒绝，程序内无法提示）|

## 4. 关键约束（红线，见 AGENTS.md §2）

1. 重启类还原/备份**必须走 Linux**（禁用 WinPE/WinRE 作为**必需**执行环境；PE 只是可选加速）。
2. 读磁盘/分区信息**禁用 WMI**（PE 不可用），只用 Win32 API 白名单。
3. BCD 严格按成熟方案（`\grldr.mbr` + `/application bootsector`），严禁自行发明。
4. `libwim` 只**动态链接**（LGPLv3）；**禁止**抄 `wimlib-imagex`(GPLv3)/GRUB4DOS/Dism++ 代码。
5. 跨层契约（`restore-task.conf` / `progress.json` / `_zjresy*.log`）改字段必须双端同步发版。

## 5. 已知短板

- **只出 64 位（x64）**：32 位 Windows / 32 位 PE 上无法运行（x64 exe 由系统层面拒绝，程序内无法提示 ✗）。
  要支持 32 位需三样东西：① 另装 **i686-w64-mingw32 工具链**；② 取官方 **32 位 `libwim-15.dll`**
  （wimlib 官方同时发 `windows-i686` / `windows-x86_64` 包 ✓）；③ Makefile 加 `ARCH=x86` 分支。
  **救援层不受影响**（Linux 侧与宿主位数无关 ✓）；但 **UEFI 引导资产是 x64**（`shimx64.efi`/64 位内核），
  32 位 UEFI（IA32）需另找 `shimia32.efi`+32 位内核 —— 极少见；32 位机器基本都走 **BIOS+GRUB4DOS** ✓。
- **Windows 7**：exe 与 `libwim-15.dll` 依赖 UCRT（Win10 内置、Win7 无）→ 装 VC++ 运行库即可用
  （**2026-09-20 实测通过**，且用它还原 Win10 镜像也正常启动）；要做到"用户零安装"，
  把 UCRT DLL 放进 `third_party/ucrt/x64/` 随包分发（机制已就绪，见 `third_party/ucrt/README.txt`）。
- **服务器 RAID**：驱动**已补进包**（从 Ubuntu `linux-modules-extra` 挑了 26 个：
  `vmd`/`megaraid`/`isci`/`pm80xx`/`mvsas`/`smartpqi`/`hpsa`/`arcmsr`/老 QLogic-BusLogic…，
  约 1.2MB；QEMU 实测加载通过 ✓）→ 待**真机阵列卡**验收。
- **PE 直装**：代码已就绪（目标分区未被占用时自动就地还原），未在真 PE 里实测。
