## 8. GUI 自动化配方（实验室，2026-10-07 run #14 全链打通）

> 这个 GUI 无 UI Automation 支持，只能 P/Invoke 模拟真实输入。踩过的坑全部记在这里，后续 GUI 类测试（备份取消等）直接复用。

- **启动**：RunOnce（宿主机离线 `reg load` 写 SOFTWARE hive 的 `...\CurrentVersion\RunOnce\zjguitest` = `C:\zjgui\run-gui.cmd`）；GUI 包 = dist 全拷到 guest `C:\zjgui`；每次跑前重写 RunOnce + 清日志。
- **找窗口**：`EnumWindows` + `GetClassName=="SysRecoverUI"`（`FindWindow` 实测不可靠，返回 0）；`GetWindowRect` 取矩形（本机 268,180,1013,590；client 坐标 = screen − 268,180）。
