## 1.1 空间预检公式（用户 2026-10-09 规格；**不需要实验，算术即可**）

```
需要空闲 ≥ 解压内容量 + pagefile.sys + swapfile.sys + hiberfil.sys + 日志/余量
```
- **解压内容量**：镜像**未压缩**大小（已有 `WimEngine::ImageSize` = `TOTALBYTES − HARDLINKBYTES`，PIT-073 实测校准）；
- **pagefile/swapfile/hiberfil**：读当前系统实际值（`GetFileAttributesEx` 取大小；备份排除清单不含它们 → 新系统首启会重建，需预留）；
- **余量**：日志/回收站/系统还原点等，按内容量 ×10% + 2GB 抛算；
- **策略（用户规格）**：**够 → 直接开始，不询问**；**不确定/临界 → 弹一次让用户确认**（不做"2×"的机械门槛——旧树空间本来已被占用，解压只需"新增一份"）。

> 2× 是"新旧共存"的必然（用户 2026-10-09 确认："不管怎么算也必须要 2 份空间"）——
> 但**不需要实验验证**，公式化预检即可。

## 3. 交换脚本原型（`zjswap.sh`，救援层；先做非事务版）

```sh
#!/bin/sh
# 用法: zjswap.sh <目标分区设备>   （原型：非事务；正式版需事务化+回滚，见 docs/21 P1）
T="$1"; M=/mnt/zj_swap
mkdir -p "$M"; mount -t ntfs3 "$T" "$M" || ntfs-3g -o force "$T" "$M" || exit 1
mkdir -p "$M/~old"
for d in "$M"/* "$M"/.[!.]*; do
    b=$(basename "$d")
    case "$b" in ~new|~old|'$RECYCLE.BIN'|'System Volume Information') continue;; esac
    mv "$d" "$M/~old/" || echo "WARN: move old $b failed"
done
for d in "$M/~new"/* "$M/~new"/.[!.]*; do
    b=$(basename "$d")
    mv "$d" "$M/" || echo "WARN: move new $b failed"
done
sync; umount "$M"; echo "swap done"
```
